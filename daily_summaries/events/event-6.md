# Rocket Lab to test Space Force data network connection in orbit in 2027

Rocket Lab will use a Photon spacecraft to test in-orbit interoperability with the Space Data Network's core infrastructure, which the article says was built by SpaceX, in 2027.

## Industry implication

If successful, the test would demonstrate third-party (non-SpaceX) spacecraft can connect with the Space Data Network core infrastructure, potentially broadening commercial access to U.S. defense data networks and validating Rocket Lab's Photon for defense-oriented networking tasks. It could accelerate integration between commercial satellite operators and government data-networking infrastructure.

## Key facts

- Rocket Lab will use a Photon spacecraft to test interoperability with the Space Data Network's core infrastructure.
- The summary states the Space Data Network core infrastructure was built by SpaceX.
- The test is planned to occur in 2027.
